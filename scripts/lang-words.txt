# Project vocabulary for harness-kit itself — and a worked example of the file it ships.
#
# The template version of this file (template/scripts/lang-words.txt) goes out empty, for projects to
# fill in. This one is real, and it exists because harness-kit hits the one case every detector hits:
# a repo that TESTS a Vietnamese detector has to contain Vietnamese.
#
# tests/run-tests.sh holds the probe strings the check is asserted against. Those words are fixtures,
# not prose — the same reason scripts/check-lang.mjs excludes itself. Rather than contorting the test
# into unreadable string concatenation to hide from its own subject, it is skipped and said so here.
#
# This is the honest use of !skip: a file whose non-English content is the point. It is not a place to
# park code you did not feel like translating.
!skip tests/run-tests.sh

# .superpowers/ is the SDD working ledger — briefs, reports, and captured review diffs from earlier
# sessions. The diffs are snapshots of code as it was, so they hold whatever that code held. It is
# gitignored scratch, not project content, and skipping it here means the validator gives the same
# answer whichever skip-dirs argument it happens to be invoked with.
!skip .superpowers/
# .worktrees/ holds checkouts of other branches; each one validates itself.
!skip .worktrees/
